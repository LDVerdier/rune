# Project: Rune

## Tech Stack
- React Router v7, React 19, HeroUI, Tailwind CSS v4, Framer Motion
- TypeScript, ESLint, Vitest + Testing Library

## Verification Commands
- Lint: `npm run lint`
- Typecheck: `npm run typecheck`
- Tests: `npm run test`

## Post-Implementation Rule
After finishing any implementation plan, ALWAYS run the full verification suite before reporting completion:
1. `npm run lint` — fix any lint errors
2. `npm run typecheck` — fix any type errors
3. `npm run test` — fix any failing tests
